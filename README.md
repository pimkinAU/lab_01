# Лабораторная работа 1 — Калькулятор и конвертер величин

Консольная программа на Python: умеет считать арифметические выражения
и переводить величины (длина, масса, температура) из одних единиц в другие.

## Как запустить

Python 3.10 или новее.

```bash
pip install -e .
```

## Примеры

```bash
python3 -m toolkit calc "10 + 3 * 20"
# 70.0

python3 -m toolkit convert 10 --from mm --to m
# 0.01

python3 -m toolkit convert 10 --from k --to c
# -263.15
```

Если ввести что-то некорректное (например, поделить на ноль или указать
неизвестную единицу), программа выведет ошибку в stderr и завершится
с кодом 2:

```bash
python3 -m toolkit calc "10 / 0"
# Ошибка: Деление на ноль

python3 -m toolkit convert 10 --from km --to kg
# Ошибка: Несовместимые единицы измерения
```

## Какие единицы поддерживаются

- длина: mm, cm, m, km
- масса: g, kg
- температура: c, f, k

Из одной группы в другую переводить нельзя (например, метры в килограммы).

## Структура проекта

- `calculator.py` — вычисление выражений
- `converter.py` — перевод величин
- `errors.py` — свои классы ошибок
- `__main__.py` — ввод аргументов командной строки, запуск
- `tests/` — тесты
